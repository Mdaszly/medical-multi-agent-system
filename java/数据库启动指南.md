# 数据库启动完整指南

## 📋 前置条件检查

### 1. 检查Docker Desktop是否安装并运行

**Windows系统检查：**
```powershell
# 在PowerShell中执行
docker --version

# 如果显示版本信息，说明已安装
# 如果提示"无法识别"，需要先安装Docker Desktop
```

### 2. Docker Desktop安装（如果未安装）

1. 访问 https://www.docker.com/products/docker-desktop
2. 下载Windows版本安装包
3. 安装后重启电脑
4. 启动Docker Desktop（需要等待Docker引擎完全启动）

## 🚀 数据库启动步骤

### 步骤1：进入项目目录

```powershell
# 使用PowerShell
cd d:\IDEA\multi-agent\medical-multi-agent-system\python
```

### 步骤2：启动数据库服务

#### 方案A：只启动必要的数据库（推荐）
```powershell
# 启动PostgreSQL、Neo4j、Redis
docker compose up -d postgres neo4j redis
```

#### 方案B：启动全部服务（包含Python API）
```powershell
# 启动所有服务
docker compose up -d
```

### 步骤3：验证容器状态

```powershell
# 查看运行中的容器
docker compose ps

# 或者查看所有容器
docker ps
```

**预期输出应该看到3个容器：**
- postgres (端口5432)
- neo4j (端口7474, 7687)
- redis (端口6379)

### 步骤4：等待数据库初始化

**PostgreSQL需要约5-10秒完成初始化：**
```powershell
# 查看PostgreSQL日志
docker compose logs -f postgres

# 看到 "database system is ready to accept connections" 表示就绪
# 按Ctrl+C退出日志查看
```

### 步骤5：验证数据库连接

#### 验证PostgreSQL
```powershell
# 测试PostgreSQL连接
docker compose exec postgres pg_isready -U postgres

# 应该返回：/var/run/postgresql:5432 - accepting connections
```

#### 验证Redis
```powershell
# 测试Redis连接
docker compose exec redis redis-cli ping

# 应该返回：PONG
```

#### 验证Neo4j
在浏览器中访问：http://localhost:7474
- 用户：neo4j
- 密码：neo4jpass

## 🔧 常见问题排查

### 问题1：Docker命令无法识别

**症状：**
```
docker : 无法将"docker"项识别为 cmdlet、函数、脚本文件或可运行程序的名称
```

**解决方案：**
1. 确认Docker Desktop已安装
2. 重启Docker Desktop
3. 重启PowerShell或命令提示符

### 问题2：端口被占用

**症状：**
```
Bind for 0.0.0.0:5432 failed: port is already allocated
```

**解决方案：**
```powershell
# 查找占用端口的进程
netstat -ano | findstr :5432

# 或者停止占用端口的程序
# 如果之前有旧的PostgreSQL，先停止它
```

### 问题3：数据库初始化失败

**症状：** 容器不断重启

**解决方案：**
```powershell
# 1. 停止所有容器
docker compose down

# 2. 删除数据卷（警告：会丢失所有数据）
docker volume rm python_pgdata python_neo4jdata

# 3. 重新启动
docker compose up -d postgres neo4j redis
```

### 问题4：应用程序无法连接数据库

**症状：**
```
Communications link failure
Connection refused
```

**排查步骤：**
1. 确认容器正在运行：`docker compose ps`
2. 检查PostgreSQL日志：`docker compose logs postgres`
3. 验证端口是否开放：`netstat -ano | findstr :5432`
4. 确认环境变量已正确设置

## 🛑 停止数据库服务

### 停止但保留数据
```powershell
docker compose stop
```

### 停止并删除容器（保留数据卷）
```powershell
docker compose down
```

### 完全清除（警告：删除所有数据）
```powershell
docker compose down -v
```

## 🎯 完整启动流程（复制粘贴版）

```powershell
# 1. 进入项目目录
cd d:\IDEA\multi-agent\medical-multi-agent-system\python

# 2. 启动数据库
docker compose up -d postgres neo4j redis

# 3. 等待10秒让数据库初始化
Start-Sleep -Seconds 10

# 4. 检查容器状态
docker compose ps

# 5. 验证PostgreSQL
docker compose exec postgres pg_isready -U postgres

# 6. 验证Redis
docker compose exec redis redis-cli ping

# 7. 返回Java目录
cd ..\java

# 8. 启动Spring Boot应用
.\set-env.ps1
mvn spring-boot:run
```

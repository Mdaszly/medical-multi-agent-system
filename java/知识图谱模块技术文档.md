# 知识图谱模块技术文档

---

## 1. 模块概述

### 1.1 功能定位

知识图谱模块是医疗多Agent系统的核心组件，用于存储和管理医疗领域实体及其关系，支持症状诊断、疾病分类、ICD编码映射等智能医疗功能。

### 1.2 核心能力

| 能力 | 描述 |
| ---- | ---- |
| 数据导入 | 支持CSV/JSON格式数据批量导入 |
| 实体管理 | 症状、疾病、ICD编码等实体的增删改查 |
| 关系构建 | 建立实体间的语义关联（症状→疾病→ICD编码） |
| 图谱查询 | 支持Cypher查询语言进行灵活的图数据查询 |
| 统计分析 | 提供图谱数据统计和分析功能 |


### 2.2 核心实体模型

#### 2.2.1 节点实体

| 实体类型 | 标签 | 核心属性 |
| ---- | ---- | ---- |
| 症状 | `Symptom` | id, name, code, categoryCode, severity, frequency |
| 疾病 | `Disease` | id, name, diseaseCode, icd10Code, category, system |
| ICD编码 | `ICD10` | code, descriptionCn, chapterCode, diseaseClass |

#### 2.2.2 关系类型

| 关系类型 | 起始节点 | 目标节点 | 描述 |
| ---- | ---- | ---- | ---- |
| `INDICATES` | Symptom | Disease | 症状指示疾病 |
| `CLASSIFIED_AS` | Disease | ICD10 | 疾病分类到ICD编码 |

### 3.1 配置类

**Neo4jConfig.java** - Neo4j驱动配置

```java
@Bean(destroyMethod = "close")
public Driver neo4jDriver() {
    Config config = Config.builder()
            .withEncryptionLevel(neo4jProperties.getEncrypted() 
                    ? EncryptionLevel.REQUIRED 
                    : EncryptionLevel.DISABLED)
            .withTrustStrategy(TrustStrategy.trustAllCertificates())
            .withMaxConnectionPoolSize(neo4jProperties.getMaxConnectionPoolSize())
            .withConnectionTimeout(neo4jProperties.getConnectionTimeoutDuration())
            .build();

    driver = GraphDatabase.driver(
            neo4jProperties.getUri(),
            AuthTokens.basic(neo4jProperties.getUsername(), neo4jProperties.getPassword()),
            config
    );
    
    // 连接验证
    try (Session session = driver.session()) {
        session.run("RETURN 1 AS num").single();
    }
    
    return driver;
}
```

### 3.2 服务层核心方法

**KnowledgeGraphService.java** - 节点Upsert操作

```java
public void upsertNode(BaseNode node) {
    String label = node.getLabel();
    String cypher = String.format(
            "MERGE (n:%s {name: $name}) " +
            "SET n += $props " +
            "RETURN n",
            label
    );
    
    Map<String, Object> params = new HashMap<>();
    params.put("name", node.getName());
    params.put("props", node.toNeo4jProperties());
    
    try (Session session = neo4jDriver.session()) {
        session.executeWrite(tx -> {
            tx.run(cypher, params);
            return null;
        });
    }
}
```

**KnowledgeGraphService.java** - 关系创建

```java
public void createRelationship(KnowledgeRelation relation) {
    String cypher = String.format(
            "MATCH (source:%s {name: $sourceName}) " +
            "MATCH (target:%s {name: $targetName}) " +
            "CREATE (source)-[r:%s]->(target) " +
            "SET r = $props",
            relation.getSourceLabel(),
            relation.getTargetLabel(),
            relation.getType()
    );
    
    Map<String, Object> params = new HashMap<>();
    params.put("sourceName", relation.getSourceName());
    params.put("targetName", relation.getTargetName());
    params.put("props", buildRelationProperties(relation));
    
    try (Session session = neo4jDriver.session()) {
        session.executeWrite(tx -> {
            tx.run(cypher, params);
            return null;
        });
    }
}
```

```java
private ImportTaskDTO importSymptoms(String filePath, 
                                     ImportTaskDTO.ImportConfig config,
                                     ImportTaskDTO task) {
    CsvImportService.ImportStats stats = csvImportService.importCsv(
            filePath,
            config != null && config.getSkipHeader() != null ? config.getSkipHeader() : true,

            }
    );
```

## 4. REST API接口

### 4.1 接口列表

| HTTP方法 | 路径 | 功能 |
| ---- | ---- | ---- |
| POST | `/api/knowledge-graph/import` | 导入数据文件 |
| GET | `/api/knowledge-graph/import/{taskId}` | 查询导入任务状态 |
| GET | `/api/knowledge-graph/node/{label}/{name}` | 根据名称查询节点 |
| GET | `/api/knowledge-graph/relations` | 查询节点关系（Query参数版） |
| POST | `/api/knowledge-graph/cypher` | 执行Cypher查询 |
| GET | `/api/knowledge-graph/statistics` | 获取统计信息 |
| POST | `/api/knowledge-graph/index` | 创建索引 |
| DELETE | `/api/knowledge-graph/all` | 清空所有数据 |

### 4.2 接口详细说明

#### 4.2.1 数据导入接口

**请求**:
```
POST /api/knowledge-graph/import
Content-Type: multipart/form-data

参数:
- file: 文件 (required)
- entityType: 实体类型 (required, 值: symptom/disease/icd10/relation)
- skipHeader: 是否跳过表头 (optional, 默认: true)
- delimiter: 分隔符 (optional, 默认: ,)
```

**响应**:
```json
{
  "taskId": "import-xxx",
  "status": "COMPLETED",
  "entityType": "symptom",
  "totalRecords": 20,
  "successCount": 20,
  "failedCount": 0,
  "message": "导入成功"
}
```

#### 4.2.2 节点关系查询接口

**请求**:
```
GET /api/knowledge-graph/relations?label=Symptom&name=头痛&depth=1
```

**响应**:
```json
{
  "queryId": "xxx",
  "totalCount": 5,
  "nodes": [...],
  "relations": [...],
  "paths": [...]
}
```

## 5. 使用方法

### 5.1 数据导入流程

#### 步骤1：准备CSV数据文件

**症状数据文件格式** (`symptoms_data_standard.csv`):
```csv
id,name,code,category_code,category_name,description,body_part,pinyin,frequency,severity,urgent
S001,头痛,R51,R02,神经系统疾病,头部疼痛的感觉,头部,toutong,3,2,false
```

**关系数据文件格式** (`symptom_disease_relations.csv`):
```csv
source_id,source_name,source_label,target_id,target_name,target_label,type,description,weight,urgent
,头痛,Symptom,,偏头痛,Disease,INDICATES,头痛可能是偏头痛,0.8,
```

#### 步骤2：调用导入接口

使用Apifox或curl导入数据：

```bash
# 导入症状数据
curl -X POST http://localhost:8080/api/knowledge-graph/import \
  -F "file=@symptoms_data_standard.csv" \
  -F "entityType=symptom"

# 导入关系数据
curl -X POST http://localhost:8080/api/knowledge-graph/import \
  -F "file=@symptom_disease_relations.csv" \
  -F "entityType=relation"
```

#### 步骤3：验证数据

在Neo4j Browser中执行查询：

```cypher
-- 查看所有节点
MATCH (n) RETURN labels(n), n.name LIMIT 20

-- 查看所有关系
MATCH (n)-[r]->(m) RETURN n.name, type(r), m.name LIMIT 20
```

### 5.2 Cypher查询示例

```cypher
-- 查询症状"头痛"相关的疾病
MATCH (s:Symptom {name: '头痛'})-[r:INDICATES]->(d:Disease)
RETURN s.name, d.name, d.description

-- 查询疾病的ICD编码
MATCH (d:Disease {name: '偏头痛'})-[r:CLASSIFIED_AS]->(i:ICD10)
RETURN d.name, i.code, i.descriptionCn

-- 查询完整路径（症状→疾病→ICD）
MATCH path = (s:Symptom)-[*1..2]->(i:ICD10)
RETURN path
```

## 7. 注意事项

### 7.1 配置要求

- **Neo4j版本**: 5.x (推荐5.24.0+)
- **Java版本**: 21
- **端口配置**: 
  - Bolt协议端口: 7687
  - HTTP端口: 7474

### 7.2 常见问题

| 问题 | 原因 | 解决方案 |
| ---- | ---- | ---- |
| 节点标签为null | @Builder创建对象时默认构造函数不执行 | 实体类重写getLabel()方法 |
| 关系导入失败 | CSV字段名与代码解析不一致 | 使用下划线命名格式 |
| 数据写入不生效 | Neo4j 5.x需要显式事务提交 | 使用executeWrite()方法 |
| 中文参数错误 | URL路径中的中文未编码 | 使用Query参数或开启URL编码 |

### 7.3 性能优化建议

1. **批量导入**: 对于大量数据，使用批量导入接口
2. **索引优化**: 为常用查询字段创建索引
3. **查询限制**: 复杂查询添加LIMIT限制返回数量
4. **连接池配置**: 根据并发量调整连接池大小

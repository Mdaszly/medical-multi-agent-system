# 环境变量配置说明

## 已配置的文件

1. `set-env.bat` - Windows批处理脚本
2. `set-env.ps1` - PowerShell脚本（推荐）
3. `src/main/resources/application.yml` - Spring Boot配置文件（已更新）

## 使用方法

### 方法一：使用PowerShell脚本（推荐）

在项目根目录打开PowerShell，运行：

```powershell
.\set-env.ps1
```

然后启动应用：

```powershell
mvn spring-boot:run
```

### 方法二：使用批处理脚本

在项目根目录打开CMD，运行：

```cmd
set-env.bat
```

然后启动应用：

```cmd
mvn spring-boot:run
```

### 方法三：直接设置环境变量

在运行Maven命令前手动设置：

```powershell
$env:OPENAI_API_KEY="sk-c4cf1c2cf37849baa21a536bc60ced8e"
$env:POSTGRES_PASSWORD="postgres"
mvn spring-boot:run
```

## 环境变量说明

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| OPENAI_API_KEY | API密钥（阿里云DashScope） | 必填 |
| OPENAI_MODEL | 使用的模型 | qwen-max |
| OPENAI_BASE_URL | API端点地址 | https://dashscope.aliyuncs.com/compatible-mode/v1 |
| POSTGRES_HOST | PostgreSQL主机 | localhost |
| POSTGRES_PORT | PostgreSQL端口 | 5432 |
| POSTGRES_DB | PostgreSQL数据库名 | clinical_decision |
| POSTGRES_USER | PostgreSQL用户名 | postgres |
| POSTGRES_PASSWORD | PostgreSQL密码 | postgres |
| NEO4J_URI | Neo4j连接URI | bolt://localhost:7687 |
| NEO4J_USER | Neo4j用户名 | neo4j |
| NEO4J_PASSWORD | Neo4j密码 | neo4j |
| REDIS_HOST | Redis主机 | localhost |
| REDIS_PORT | Redis端口 | 6379 |

## 注意事项

⚠️ **重要提示**：
- 本项目已配置为使用**阿里云通义千问**（qwen-max）
- 需要使用阿里云DashScope的API密钥
- API端点已设置为：`https://dashscope.aliyuncs.com/compatible-mode/v1`

⚠️ **安全提示**：请勿将包含真实API密钥的文件提交到Git仓库！

⚠️ 记得先启动基础设施（PostgreSQL、Neo4j、Redis）：
```bash
cd ../python
docker-compose up -d postgres neo4j redis
cd ../java
```

## 如何获取阿里云DashScope API密钥

1. 访问 [阿里云DashScope控制台](https://dashscope.aliyuncs.com/)
2. 注册/登录阿里云账号
3. 创建API-KEY
4. 将API密钥替换配置文件中的 `sk-c4cf1c2cf37849baa21a536bc60ced8e`
